# 🎀 VELVET BLUSH

### Where Beauty Meets Elegance ✨

Welcome to **Velvet Blush**, a modern and stylish beauty website designed for makeup lovers and beauty enthusiasts. This website features a soft pink aesthetic, elegant layouts, attractive visuals, and interactive elements to create a beautiful browsing experience.

---

## 💗 ABOUT THE PROJECT

Velvet Blush is a beauty and makeup-themed website created with a feminine-inspired pink color palette and a modern user interface. It showcases beauty products, makeup essentials, and stylish visual elements in an elegant and user-friendly way.

---

## 💻 TECHNOLOGIES USED

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, animations, and responsive design.
- **JavaScript** – Interactive features and dynamic functionality.
- **Bootstrap** – Responsive components and layouts.
- **jQuery** – Simplified JavaScript interactions.

---

## ✨ KEY FEATURES

- Elegant pink and blush-themed design.
- Modern and attractive user interface.
- Fully responsive website layout.
- Beautiful makeup and beauty visuals.
- Interactive hover effects.
- User-friendly navigation.
- Stylish product sections.
- Responsive across different screen sizes.
